🗨️ print(): fazer o computador falar

print() mostra uma mensagem na tela. O texto vai entre aspas. Em programação, texto se chama string.

print("I Competição de Programação da Start")
I Competição de Programação da Start

Repare: as aspas não aparecem na tela. Elas só avisam o Python que aquilo é texto.

⚠️ Armadilha: esquecer as aspasSem aspas, o Python acha que a palavra é o nome de uma variável que não existe. 
print(Olá)
NameError: name 'Olá' is not defined

📦 Variável: uma caixa com nome

Uma variável guarda um valor para usar depois. Pense num baú com uma etiqueta.

ano = "II"
print(ano, "Competição de Programação da Start")
II Competição de Programação da Start

Leia ano = "II" assim: "guarde o texto II na variável ano". O sinal = aqui não é o "igual" da matemática. Ele significa guardar.

No print, a vírgula separa as partes e o Python coloca um espaço entre elas sozinho.

Se a competição tiver uma terceira edição, basta trocar "II" por "III". O resto do código continua igual. Essa é a vantagem da variável.

✨ f-string: variável dentro do texto

Outra forma de juntar texto e variável: coloque a letra f antes das aspas e a variável entre chaves { }.

ano = "II"
print(f"{ano} Competição de Programação da Start")
II Competição de Programação da Start
📌 Correção do material da aulaO material diz que a variável vai "entre colchetes". O certo é entre chaves: { }. Colchetes são [ ] e não funcionam aqui.
⚠️ Armadilha: esquecer o fSem o f, as chaves viram texto comum: 
nome = "Ana"
print("Oi, {nome}!")
Oi, {nome}!

  1. Qual das linhas dá erro: print("Oi") ou print(Oi)?
    Ver resposta

    print(Oi). Sem aspas, o Python procura uma variável chamada Oi, que não existe (NameError).

  2. O que aparece na tela com classe = "Maga" e depois print(classe, "nível 1")?
    Ver resposta

    Maga nível 1. A vírgula junta com um espaço.

  3. Que símbolo envolve a variável dentro de uma f-string?
    Ver resposta

📚 A missão: campanha de leitura

A escola dá pontos por livro lido: ficção = 10, não-ficção = 8, infantil = 6. Rodrigo leu um livro de cada. Quantos pontos ele fez?

Cada categoria vira uma variável. Número vai sem aspas. Outra variável guarda a soma.

livro_ficcao = 10
livro_nficcao = 8
livro_infantil = 6

pontos_rodrigo = livro_ficcao + livro_nficcao + livro_infantil

print(f"Os pontos totais do Rodrigo são: {pontos_rodrigo}")
Os pontos totais do Rodrigo são: 24

✖️ Multiplicação

O asterisco * é a multiplicação. Como na matemática, ela é feita antes da soma.

livro_ficcao = 10
livro_infantil = 6
pontos = 2 * livro_ficcao + livro_infantil
print(pontos)
26

FASE 3 · AULA 3

Distribuindo itens

Você vai aprender: pedir dados com input() · converter com int() · dividir com // · ver o resto com %

🎴 A missão: divisão do tesouro

Problema adaptado da Olimpíada Brasileira de Informática (OBI) 2020.

A turma achou um envelope de figurinhas. João, o dono, propôs: cada amigo recebe a mesma quantidade e João recebe o dobro de um amigo. A divisão é exata: não sobra nem falta.

Sabendo o total de figurinhas e o número de amigos (sem contar o João), quantas figurinhas o João recebe?

🧠 Primeiro a matemática, depois o código

Se cada amigo recebe x, o João recebe 2x. É como se o João contasse por dois amigos. Então dividimos o total em amigos + 2 partes iguais:

🧮
cada amigo = total ÷ (amigos + 2)
⬇
👑
João = 2 × cada amigo

Exemplo da OBI: 221 figurinhas e 11 amigos → 221 ÷ 13 = 17 por amigo → João recebe 34. Confira: 11 × 17 + 34 = 221. ✔

⌨️ input(): o programa pergunta

Até agora os valores estavam escritos no código. Com input(), o programa para e espera a pessoa digitar e apertar Enter. O texto entre aspas aparece como pergunta.

📌 Regra de ouroinput() sempre devolve texto, mesmo que a pessoa digite um número. Por isso usamos int(), que transforma o texto em número inteiro.

Leia a linha de dentro para fora:

total_figurinhas = int(input("Digite o total de figurinhas: "))
1️⃣
input(...) mostra a pergunta e recebe o que a pessoa digitou: o texto "221"
⬇
2️⃣
int(...) transforma o texto "221" no número 221
⬇
3️⃣
= guarda o número na variável total_figurinhas

Sem o int(), acontece aquilo da Fase 2: texto não faz conta.

x = input()
print(x + x)
7
77
x = int(input())
print(x + x)
7
14

Nos exemplos, a primeira linha da tela (7) é o que a pessoa digitou.

⚠️ Armadilha: digitar letrasint() só entende dígitos. Se a pessoa digitar "onze": 
int("onze")
ValueError: invalid literal for int() with base 10: 'onze'

🏆 O programa completo

total_figurinhas = int(input("Digite o total de figurinhas: "))
numero_amigos = int(input("Digite o número de amigos: "))

figurinhas_amigos = total_figurinhas // (numero_amigos + 2)

figurinhas_joao = 2 * figurinhas_amigos

print(f"João recebeu {figurinhas_joao} figurinhas.")
Digite o total de figurinhas: 221
Digite o número de amigos: 11
João recebeu 34 figurinhas.
📌 Correções do material da aula 1) O texto do material escreve figurinhas_amigos 2 *. Isso dá SyntaxError. O certo é 2 * figurinhas_amigos (a imagem do código no material está certa).
2) print(f) não existe como função separada: o f faz parte do texto, antes das aspas: print(f"...").
⚠️ Armadilha: tirar os parênteses total_figurinhas // numero_amigos + 2 faz a divisão primeiro e só depois soma 2. Com 221 e 11, o João receberia 44 em vez de 34. Os parênteses em (numero_amigos + 2) são obrigatórios.

🔍 E o exemplo de 100 figurinhas e 5 amigos?

O material testa com 100 e 5 e mostra "João recebeu 28". Mas veja: 100 ÷ 7 dá 14 e sobram 2.

print(100 // 7, 100 % 7)
14 2

O enunciado diz que a divisão é exata, então 100 e 5 não é uma entrada válida para esse problema. O programa não está errado; o teste é que não segue a regra. Com 5 amigos, totais como 70, 77 ou 84 funcionam (múltiplos de 7).

Curiosidade: na prova de verdade da OBI, o programa não pode mostrar frases como "Digite o total". A correção é automática e compara só o número da resposta.
🎯 Teste rápido da Fase 3
  1. O que input() sempre devolve?
    Ver resposta

    Texto (string). Por isso usamos int() para fazer contas.

  2. Quanto dá 17 // 5 e 17 % 5?
    Ver resposta

    3 e 2. O 5 cabe 3 vezes no 17 (15) e sobram 2.

  3. Com 1000 figurinhas e 8 amigos, quanto o João recebe?
    Ver resposta

    1000 // (8 + 2) = 100 por amigo. João recebe 200.
