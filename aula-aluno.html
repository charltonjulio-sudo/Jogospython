🐍 Python no navegador

    
O Python roda no seu navegador, sem conta e sem instalar nada. Na primeira vez baixa uns 6 MB; depois fica no cache. Quando o programa pede input(), aparece uma caixa para digitar. Um programa que passa de 5 segundos sem pedir nada é interrompido (laço infinito). Para os trabalhos da aula, continue usando o Google Colab.
